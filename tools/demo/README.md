# FiresChain Tools

[工具目录](https://fireschain.org/tools/) 由 GitHub Pages 提供。目录的应用路由使用 `#flow`、`#yuhun` 和 `#team`。旧的 `/tools/demo/` 地址会保留片段并跳转到 `/tools/`。

三个预览载入同域的线上应用。目录通过 iframe 文档的 `data-tools-theme` 切换应用自身提供的 `light`、`dark` 和 `original` 配色。主题切换保留应用当前操作状态。应用链接也可以独立打开。

可在本地用静态文件服务检查目录和搜索。应用预览的配色切换需要从 `https://fireschain.org` 打开，确保目录和应用同源。
